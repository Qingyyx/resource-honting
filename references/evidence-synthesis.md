# 证据综合：多条信息放在一起怎么判断

> 用途：手上已有 ≥2 条证据、要合成一个结论时读本文件。
> 单条信息/单个来源的可信度评估见 [credibility-framework.md](credibility-framework.md)，深度调研的分层取证见 [deep-research-sources.md](deep-research-sources.md)。本文件只处理"合并"这一步——单条都可信，合起来仍可能得出错误结论。

## 零、先分清任务类型

不同问题用不同方法。判错类型会做无用功。

| 任务 | 典型问法 | 用什么 |
|---|---|---|
| 事实确认 | "X 是不是 Y""有没有 Z" | §1 断言分解 |
| 方案选择 | "选 A 还是 B""为什么会出现 X" | §2 竞争假设 |
| 数量估计 | "大概多少""占几成" | §3 区间与稳健性 |
| 真实性判断 | "这事是真的吗" | [credibility-framework.md](credibility-framework.md)（已有，不重复） |
| 单一事实、一条证据就够 | — | 跳过本文件，直接按 SKILL.md §6 汇报 |

`effort=quick` 时不做本文件任何步骤。`standard` 只做 §1；`deep` 做 §1–§4。

## 一、断言分解：把复合说法拆成可核的原子

**问题**：真实信息是复合的。"X 公司 2024 年营收 10 亿、毛利率 30%、市占率第一"是三个独立断言，可能一真两假。整体标一个【中】无法定位哪部分有问题。

**做法（FEVER 范式）**：

1. **拆**：这句话里有几个可以独立核实的断言。
2. **逐条判三值**：`支持` / `反驳` / `证据不足`。
3. **每个判定必须挂一句原文引用**。没有引用 = 没核过。
4. **汇总**：几条被反驳、几条查不到、几条有证据。

| 断言 | 判定 | 证据 |
|---|---|---|
| 2024 年营收 10 亿 | 反驳 | 年报披露 8.2 亿 |
| 毛利率 30% | 支持 | 年报第 42 页 |
| 市占率第一 | 证据不足 | 只找到厂商自述 |

**规则**：

- **只拆影响结论的部分**。定义、背景、常识不拆，否则产生大量无意义原子。
- **"证据不足"要真的说出来**。这是三值里最有用的一档，逼自己承认查不到，而不是用"可能/大概"糊过去。
- **一条被反驳，整个复合结论降级**。不能说"大部分是对的"就保留原结论。
- 分解粒度会显著改变下游判定（Wanner et al. 2024 实测）。拆到"能独立找到证据"为止，不要更细。

## 二、竞争假设：当证据同时支持多个解释

**问题**：多数人的本能是收集**支持**自己偏好解释的证据。当证据指向多个可能原因时，这个本能会得出错误结论。

**做法（ACH 简化版，三步）**：

1. **列假设**：把所有说得通的解释都列出来（3–5 个），包括你不信的那个。**假设集不全，后面全白做。**
2. **建矩阵**：证据 × 假设，每格标 `一致` / `不一致` / `无关`。
3. **选"被证伪最少"的假设**，不是"被支持最多"的。

示例（判断一份资料为什么搜不到）：

| 证据 | H1 源没收录 | H2 权限/付费墙 | H3 术语用错 | 诊断性 |
|---|---|---|---|---|
| 官方站内搜到该文件 | **不一致** | 一致 | 一致 | 高 → 排除 H1 |
| 搜到摘要页但全文 403 | 一致 | 一致 | 不一致 | 中 |
| 换英文术语后命中 | 不一致 | 一致 | **不一致** | 高 → 排除 H1/H3 |
| 同义词全无结果 | 一致 | 一致 | 一致 | **零 → 删掉** |

结论：H2。全程没有"数票"，而是靠两条高诊断性证据排除了两个假设。

**诊断性原则**（这一步是重点）：

- 对所有假设都同样可能的证据，**信息量为零**，哪怕它"支持"了你的结论——直接从矩阵删掉。
- 一条能**排除**某假设的证据，价值高于三条**支持**另一假设的证据。
- 最常见的错误是拿"大家都这么说"当证据，而它对每个假设都成立。

**必须附加的两步**：

- **关键假设检查**：结论依赖哪些隐含假设？逐条问"如果这条错了，结论还成不成立"。大错几乎都出在没人检查的假设上。
- **敏感性**：拿掉最关键的一到两条证据，结论变不变。变 = 结论挂在一根钉子上，汇报时要说。

**什么时候不用**：假设只有两个、证据一边倒时，直接判。建矩阵只在"证据看起来支持多个解释"时才有价值。

**出处与局限**：Heuer《Psychology of Intelligence Analysis》第 8 章（CIA 情报研究中心，1999）；CIA《A Tradecraft Primer》（2009）是官方简版。已知局限——假设集不全会全盘失效；格子是主观判断；学术界对其能否真正提高准确率有争议，它降低的是疏忽，不降低无知。

## 三、三角验证：独立性的三条硬判据

"两个来源说了同一件事"不等于两个来源。判独立看三条：

1. **派生关系**：B 是否引用/转载/翻译 A？同一条链只算一个。
2. **共同上游**：是否都来自同一份原始数据、同一篇通稿、同一次发布会？
3. **共同激励**：是否都从同一结论获利？（同一个品牌的两篇"测评"）

**假收敛警告**：共享同一套隐含假设的多个来源，会一致地错。看着像三方印证，其实是同一个偏见复制了三遍（Blaikie 1991 对三角验证的经典批评）。

**矛盾怎么处理**，按顺序：

1. 先查是不是**口径不同**而非事实冲突（时间、定义、统计范围不同）。
2. 口径不同 → **并列给出，说明差异来源，不取平均**。口径不同的数字平均后没有意义。
3. 真冲突且无法裁决 → **报分歧**，说明各自证据强度，不给单一结论。

## 四、信心与可能性是两个不同的轴

这是最容易混淆、也最容易误导读者的一处。

| 轴 | 问什么 | 取值 |
|---|---|---|
| **信心 confidence** | 我的证据够不够硬 | 高 / 中 / 低 |
| **可能性 likelihood** | 这件事本身发生的概率多大 | 七档（见下） |

两者正交：可以"高信心地判断这件事发生的可能性很低"，也可以"低信心地判断它很可能发生"。合成一个【高】，读者不知道你在说哪个。

**可能性用词（ODNI ICD 203 常用表述）**：

| 表述 | 概率 |
|---|---|
| 几乎不可能 | 1–5% |
| 很不可能 | 5–20% |
| 不太可能 | 20–45% |
| 大致均等 | 45–55% |
| 可能 | 55–80% |
| 很可能 | 80–95% |
| 几乎确定 | 95–99% |

英国 PHIA 分档不同且有空隙（如"现实可能"25–35%），NATO 的 likely 约 60–90%。**跨来源汇总时不要混用**；本 skill 统一用上表。

**信心怎么定**（借 GRADE 的五个降级维度，各降一级）：

| 维度 | 在证据综合里的含义 |
|---|---|
| 来源与方法质量 | 一手/二手、有无利益关系 |
| 一致性 | 多源之间是否矛盾 |
| 相关性 | 是否答的正是这个问题（人群/时间/地域错配） |
| 精确度 | 证据是否单薄、样本是否太小 |
| 选择性可得 | 是否只有一方在说话（SEO 污染、语种偏倚、只搜到营销页） |

**写法**：

- 事实、非预测 → 只标信心：`【高信心】`
- 预测、概率判断 → 信心 + 可能性：`【中信心 · 可能 55–80%】`
- 证据不足以支撑判断 → 明说：`【证据不足】`，不要降格成"低信心"——两者不同，前者是没有证据，后者是证据弱。

## 五、四件不要做的事

- **不要取平均**。口径不同的数字平均后是伪精确。
- **不要数源数代替权重**。一份监管披露 > 三条匿名转述。数量不是权重。
- **不要算精确概率**。贝叶斯更新需要可靠先验和似然，AI 给不出来；Dempster-Shafer 需要给幂集分配 mass，做出来是伪精确，且高冲突合并会得出反直觉结果（Zadeh 悖论）。要表达不确定性就用 §4 的区间和档位。
- **不要把"本轮没查到"写成"不存在"**。前者是检索结果，后者是关于世界的断言。
