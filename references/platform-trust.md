# 平台置信度分级

> 本文件提供来源评估起点，最终置信度按具体主张、原始证据、版本与利益关系判断，表中档位不是整个平台的质量保证。
> 需要评价来源时查对应条目；已有历史观察见 `field-notes.md`。新增跨任务经验按 SKILL.md 的维护规则执行；官方/专业入口与动漫游戏源见 `source-directory.md`。

## 核心判断维度

判断一个平台信息的可信度，看四个维度：

1. **内容生产者身份**：官方/机构 > 专业人士 > 有声誉的UGC > 匿名/营销号
2. **平台机制**：有无审核、有无声誉体系、有无社区筛选（点赞/投票/差评可见）
3. **利益相关性**：平台/作者是否从信息中获利（卖货的测评 < 不卖货的测评）
4. **可验证性**：信息能否被其他独立来源印证

## 置信度分档

### 🟢 高置信度（优先采用）

| 平台/源 | 适用领域 | 说明 |
|---|---|---|
| 官方文档/官网 | 技术、产品规格、政策 | 一手信息，但注意"官方口径≠客观" |
| 包注册表（npm/pypi/maven/crates/dockerhub/hf） | 对应条目的包名、版本、维护者记录 | 只能支持其记录的元数据；上传内容、包的安全性与发布者身份另行核验 |
| 学术库（arxiv/pubmed/semanticscholar/openalex/dblp/google-scholar/cnki/wanfang） | 学术条目发现、书目和引文追踪 | 索引库不是质量认证；arXiv 是预印本库，其他库也须逐条确认研究类型、评议状态、更正与撤稿。研究质量依方法和问题判断，见 deep-research-sources.md |
| 政府网站（gov-law/gov-policy） | 法律、政策 | 权威一手 |
| 官方统计（国家统计局/部委/央行/海关；国际：World Bank/OECD/IMF/IEA） | 宏观、产业规模、人口能源 | 原始表优先；国际机构也会加工成员国数据，**注意统计口径、来源、修订与时滞**。Our World in Data 等整理入口追原始数据集 |
| 上市公司披露（年报/公告/招股书；公司 IR、巨潮/披露易/SEC EDGAR） | 公司营收产能、行业微观 | L1 一手；聚合页核对原始公告，管理层报数注意口径与非经常性损益 |
| Wikipedia | 通用知识、历史、概念 | 有引用机制，但内容可能有编辑偏差；**看引用来源** |
| 大型新闻社（reuters/bbc/bloomberg） | 国际新闻、财经 | 有编辑审核，立场相对中立（仍有选择性报道） |
| 官方电商在售价格 | 指定时刻、地区和条件下的展示价 | 核对具体型号、优惠资格、税运费、库存；展示价不保证结算价 |
| 维护者仓库、官方发布页 | 项目实现、版本和已知问题 | 核验维护者身份及版本；GitHub 托管或 Stack Overflow 得票不自动保证代码与答案正确 |
| 少数派（sspai.com） | 数码/数字生活/效率工具测评 | **编辑部有内容质控**，会员制部分收入来自用户而非厂商；众测栏目公开招募普通用户实测。注意免费文章含厂商合作（会标注"广告/推广"） |
| GKmix 极客实验室（gkmix.com） | 数字生活工具（AI/流媒体/Mac软件等） | 独立开发者运营，明确宣称"100% 实验室自费真实评测"，不接厂商合作；品类窄 |
| 消费者报道（ccreports.com.cn） | 产品比较测试、消费维权 | 国内少数模仿 Consumer Reports 的媒体；更新频率低、覆盖有限 |

> 国内没有像 Consumer Reports 那样完全靠会员费生存、完全独立的大型评测机构。**对任何一篇评测，先问"谁付钱给作者了"。**

### 🟡 中置信度（可用，需留意）

| 平台/源 | 适用领域 | 说明 |
|---|---|---|
| 知乎 | 专业知识、经验分享、测评 | 优质长文多，但营销号/软文/情绪输出也多；**看答主背景和评论区验证**。判断软文：是否只推荐单一品牌、是否反复出现同一品类的好物推荐（含佣）链接。**时间锚点（2026-09 核实）**：匿名发布 2023-07-14 已下线——之后无新"匿名用户"回答，历史匿名内容也无法追溯；专业徽章 2023-06 已下线——拿它当权威的教程已过时；盐值仅自己可见，无法查他人。自称"某公司员工"者用 credibility-framework.md 第三章核验 |
| V2EX（购物节点 /go/shopping） | 电子产品、数码测评讨论 | 用户以技术人员为主，对软文敏感，节点规则要求含返利链接必须标注（如"含 AFF"）；无商业化。信息零散需自己判断 |
| Reddit | 英文产品测评、社区经验 | 投票机制有效，但 subreddit 质量差异大、可能被厂商渗透 |
| 什么值得买 (smzdm) | **只查历史低价和评论区"解毒"** | **原创评测文章堕落严重**：京东入股后好价质量下降、bug价被拦截、原创大量软文/厂商通稿、评论区水军多。**别信上面的评测文章** |
| B站 | 视频测评、教程、数码 | 高质量 up 主可信度高，但恰饭（广告）多；**看 up 主是否注明赞助** |
| 豆瓣 | 书影音评价 | 评分整体可参考，但极端评分和刷分存在 |
| 虎扑 | 体育、大众热议 | 真实用户，但情绪化内容多 |
| Hacker News | 技术新闻、行业讨论 | 高质量讨论，但偏硅谷视角 |
| 即刻 | 兴趣社区、行业动态 | 小圈子质量不错，覆盖面窄 |
| 36氪 | 科技创业资讯 | 及时，但内容有宣传成分（企业稿多） |
| 券商研报/行业研究（发现报告/慧博等聚合） | 行业数据、公司分析 | **数据部分尚可（多转引 L1），评级与预测天然偏乐观**；引用需记"机构+报告名+年月" |
| 咨询机构/智库（McKinsey/Gartner/IDC/艾瑞/QuestMobile/信通院） | 市场规模、份额、趋势 | 方法论公开的报告可用；**有客户导向/营销成分**，数字转引时追原始出处 |
| 深度播客/长访谈（小宇宙/Apple Podcasts/YouTube） | 从业者叙事、行业内幕 | L3 观点级：嘉宾头衔=自称（按 credibility-framework 第三章核验）；**其中数据必须回溯 L1 才能引用**；带文字稿/show notes 的升一档 |
| 知识星球/Substack 付费行业圈 | 垂直行业内部信息 | 付费筛选带来一定质量与利益对齐，但立场极强、无法外部验证；作线索与叙事补充 |
| ~~闲鱼/淘宝/京东的评价~~ | ~~商品口碑~~ | **已废弃（2026-08 起）**：店铺评价可刷可作假，不再作为口碑/评价信息来源。电商平台只在**确认要买什么之后**用于比价/下单/核实价格 |
| YouTube | 英文测评、教程 | 优质频道可信，但广告和恰饭普遍 |
| Bangumi/AniList/MyAnimeList/VNDB/IGDB | 动漫游戏身份、别名、版本关联 | 社区目录适合消歧与找外链；评分是偏好，关键发行信息核对官方，条目不证明资源可获取 |
| PCGamingWiki/ProtonDB/游戏专属 Wiki | 兼容性、修复、机制与攻略 | 核对游戏/系统/硬件/补丁版本及原始证据；用户报告不是普遍结论 |
| Nexus Mods/Mod DB/Steam Workshop/itch.io/BOOTH | Mod、创作者作品、素材及发布入口 | 逐项核验作者、版本、依赖和授权；平台收录不担保上传内容，优先原作者发布 |
| GitHub 社区仓库/Stack Overflow 问答 | 技术方案、排错与实用经验 | 检查可复现性、适用版本、维护者/答主身份与后续修正 |

### 🔴 低置信度（仅作线索，需交叉验证）

| 平台/源 | 适用领域 | 说明 |
|---|---|---|
| 小红书 | 种草、好物推荐、经验 | **软文/广告比例极高**，很多是素人营销；只当线索，必须多源验证 |
| 抖音/短视频 | 一切 | 碎片化、情绪化、广告多，信息密度低；**几乎不作事实依据** |

| 各类"XX测评网""XX排行榜"小站（如"有评测""家核优居"） | 商品测评 | **AI 批量生成 + SEO 关键词堆砌**，多个产品"对比"但无真实测试 |

## 购买前查证流程

判断“某商品值不值得买/哪个好”时，先查官方规格与适用品类的独立实测，再选相关社区补长期体验。数码/效率工具可参考下列路线；其他品类选择对应专业机构与社区，不要求逐个平台遍历：

1. **V2EX 搜一下**：`site:v2ex.com 产品名`，看真实用户讨论和抱怨
2. **少数派搜一下**：`site:sspai.com 产品名`，注意区分标注"广告"的内容
3. **知乎搜差评**：`产品名 + 缺点/避坑/退货`，抱怨帖通常比赞美帖真实
4. **什么值得买只查历史价格**：别信上面的评测文章，只看评论区"解毒"内容
5. **确认要买什么型号后**，再上电商平台（淘宝/京东/闲鱼等）比价、核实实时价格、下单——**电商平台只在此时使用，不用于获取评价信息**

> **核心原则**：国内没有完全独立的大型评测机构。对任何一篇评测，先问"谁付钱给作者了"。

## 社区访问权限说明（影响搜索能拿到什么）

- **V2EX**：公开技术帖可先用网页或 `site:v2ex.com` 定位；部分节点/内容可能要求登录。使用 OpenCLI 时查当前帮助，不假设存在 search 子命令。
- **Linux.do 等社区**：公开性、登录/注册规则按当前页面检查；访问受限时用可公开阅读的来源补充，不依赖历史门槛说明。
- 登录状态仅说明访问条件，不提高内容本身的可信度。

## 通用提醒

1. **权威网站 ≠ 内容全对**：Wikipedia 可能有偏差，学术论文可能被推翻，官方口径可能报喜不报忧
2. **UGC ≠ 一定不可靠**：真实用户的一手经验可能比官方宣传更真实，关键是看"身份 + 利益 + 可验证"
3. **多源验证看证据独立性与质量**：多份转载同源只算一条；两个薄弱来源一致不自动升高置信。单一现行原始记录可支持它负责发布的事实；争议结论补独立证据，矛盾时列出口径与分歧
4. **时敏性**：知识类信息看更新时间，过时的"权威"等于误导
5. **平台会变**：软文比例、社区质量都会随时间变化；发现变化时先向用户确认，再更新本文件或 field-notes.md
6. **软文有法律边界**：据市监总局《互联网广告可识别性执法指南》，"测评/体验分享+购物链接+未标广告"属违规广告。看到这种组合直接判定为软文
7. **陌生英文媒体先查评级**：Media Bias/Fact Check（mediabiasfactcheck.com）可查 6300+ 媒体的可信度与立场

> 核验方法（SIFT 四步法、软文五级分类、AI 生成内容检测）详见 `credibility-framework.md`；搜索操作符与深度研究工具见 `search-tools.md`。
