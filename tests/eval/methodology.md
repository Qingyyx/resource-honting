# 跨领域检索能力评估

用于维护本技能、比较工具或检查检索策略是否有效；普通搜索不必执行整套评测。此文件是评测方法，未填写真实任务与结果前，不代表已完成评测或达到某个找回率。

## 一、把成功条件固定下来

优先收集真实需求，包含各种资源形态：研究文献、统计数据、标准与专利、代码/模型、设备手册与部件、图书档案、课程资料、设计资产、文化作品、供应商/服务、本地资源与时敏机会等。不要只在熟悉的领域取样。

每个任务记录：用户原始表达、必须满足的条件、目标资源或可接受结果、用于证明存在的原始证据、当时的可访问状态、检查日期及时间/调用成本范围。存在性证据来自独立核查，不能只用被测搜索工具自己生成的结果。

任务至少包含以下情况，按样本规模选取：

- 已知名称但小众；只有描述/片段；专业术语与用户用词不同。
- 只有编号/型号；同名或多版本；语种/地区名称不同。
- 可直接访问；只有站内/专业字段才能定位；资源在附件、扫描件或音视频里。
- 旧名称/迁移；有目录无全文；付费/登录/地域或服务条件受限。
- 目标确实存在但访问被阻；已过期机会/售罄；近似结果很多但不满足硬条件。

“无结果”样本要有可核验的范围，例如某目录不收录、某版本未发布或某机会已截止；不要把无法证明的“全网不存在”当标准答案。

## 二、区分规则检查与实际检索

| 验证类型 | 能证明什么 | 不能证明什么 |
|---|---|---|
| 格式、脚本单元测试、本地引用检查 | 文档可加载、接口处理按约定工作、引用可发现 | 网上目标真的能找到、搜索质量提高 |
| 人工场景走查 | 规则包含合理路线与故障处理 | 模型实际会采取这些动作、目标实际存在或命中 |
| 真实检索评测 | 在当时的工具、权限与预算下完成了哪些任务 | 所有领域都有效、全网召回率或长期稳定性 |

实际评测给执行者原始需求、必要条件和相同工具条件；用于核对的目标链接与解题路径单独保存，避免把答案直接放进提示。部分领域用于改进，另留此前未见的领域检验迁移能力。若由同一执行者提前看过答案，标为回归检查，不称作盲测。

## 三、记录可解释的结果

| 指标 | 计算或记录方式 |
|---|---|
| 已知目标找回率 | 样本中找到符合硬条件的已知目标数 / 对应有效样本数；分别报告各资源类型，保留分子分母 |
| 获取验证完成率 | 完成样本预定获取验证层级的任务数 / 对应有效样本数；目录命中和实际可获取分别统计 |
| 误匹配数 | 把错误版本/时间/语种/对象、失效入口或近似项当成成功的任务数 |
| 错误否定数 | 已有存在性证据却被报告为不存在的任务数；“本轮未找到”与“当前受限”不等同不存在 |
| 来源发现能力 | 陌生领域是否找到了合适的生产者/编目/分发来源，是否突破初始目录或泛搜结果 |
| 时间与费用 | 首个合格结果时间、总耗时、查询/读取次数、实际费用或可核查估算；故障单列 |
| 失败原因 | 识别、来源选择、查询、索引、权限/网络、解析、匹配、验证或预算，允许多个原因 |

全网资源总量和当前可见集合通常未知，不能据此声称“全网召回率”。新增原始来源数、独立相关结果与已知目标找回率可以用于可重复的比较。

## 四、用结果决定下一步增强

- 找错术语/类别 → 改进需求解析、领域叫法发现与消歧。
- 专业平台未覆盖 → 改进来源角色识别、目录发现和关联线索追踪。
- 某些语种/地区/生态稳定漏检 → 对比适合该缺口的另一搜索通道；实测增益后再接入。
- 已定位但读不到 → 补对应提取、站内访问、OCR/转录等能力；不把它归为搜索引擎质量问题。
- 版本或获取条件误判 → 改进匹配和验证规则，保留反例作为回归任务。
- 工具网络/权限失败 → 修复实际连通性与授权，或明确使用替代通道；离线测试通过不能替代在线验证。

每次修改只针对已观察到的主要缺口，复测相关任务，再用保留领域观察是否泛化。比较前后保持任务约束与预算尽量一致，同时记录时间变化对网页、库存和内容可用性的影响。

原始返回和临时中间文件放 `/tmp/`；需要保留的评测报告放任务当前工作目录。报告必须区分真实执行、人工走查和未执行项，不自动把待验证经验写入平台信任表。

## 五、分层回归测试集

`tests/eval/` 把上面的方法固化成可重复运行的套件；本文件只保留方法与指标，用例和运行方式以 [README.md](README.md) 为准。

- 分层：知识层级（大众/专业/小众）× 答案类型（明确/多跳/分析/负样本），12 格，种子 24 条，目标 72 条。
- 两条线：L0 静态契约（不联网、不调模型）与 L1–L3 真实执行（调 agent、联网）分开；canary 只告警，不阻塞合并。
- 判分：优先确定性断言（gold 值 + 来源域名），只有分析型用例用 rubric 人工评审；不把引用数量当质量信号。
- 时效：gold 带 `verified_at` / `expires_at`，过期标 `STALE`，不判失败。
- 统计：24 条只能抓约 15pp 以上的分层回归，72 条约 9–12pp；不能当排行榜，也不能对单格下结论。
